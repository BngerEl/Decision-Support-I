# Decision Support I

Julia notebooks for the Decision Support I course.

## Content

- `notebooks/Exemples/`: examples presented during the course.
- `notebooks/Série 8/`: notebooks for Série 8.

## Running the notebooks

The recommended way to run the notebooks is through the Decision Support I
project on Renku.

1. Open the Renku project.
2. Launch the **Decision Support I — Julia** session.
3. Open JupyterLab.
4. Navigate to the `notebooks` directory.
5. Open the desired notebook.

The environment already contains:

- Julia
- JuMP
- Cbc
- HiGHS

No package installation is required.
